# 2. Native Swift app for macOS 26+

- Status: Accepted
- Date: 2026-09-29

## Context and problem
The app needs a menu-bar icon, global hotkey, ScreenCaptureKit, Vision OCR and EventKit, all first-class on macOS.

## Decision
Swift 6 with SwiftUI (MenuBarExtra) and AppKit where needed, minimum macOS 26. The Xcode project is generated by XcodeGen from project.yml. Logic lives in a local Swift package MemorriCore. A memorri-eval CLI target scores the pipeline.

## Consequences
Only recent macOS versions are supported. No hand-edited .pbxproj, so merges stay clean.

# 1. Record architecture decisions

- Status: Accepted
- Date: 2026-09-29

## Context and problem
Decisions made across many sessions get lost unless they are written down.

## Decision
Record architecture decisions as MADR-style ADRs in docs/architecture/decisions/, numbered sequentially. Incidents and wrong assumptions go to docs/postmortems/. Rules live in CLAUDE.md; no external docs skill.

## Consequences
Accepted ADRs are immutable; changes are made by superseding. Specs link the ADRs they depend on.
